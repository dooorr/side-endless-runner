# 横版无尽跑酷

Chrome 小恐龙式横版无尽跑酷：哥特夜里小黑猫躲避墓碑、栅栏与蝙蝠，收集金币与道具，挑战本地排行榜。

**在线试玩：** [dooorr.github.io/side-endless-runner](https://dooorr.github.io/side-endless-runner/)（GitHub Pages）

## 运行

1. 用浏览器打开 `index.html`，或
2. 在 VS Code 安装 Live Server 后右键「Open with Live Server」

点击画布可获取焦点，避免按键无效。

## 操作

| 操作 | 按键 |
|------|------|
| 跳跃 / 二段跳 | 空格 / 鼠标左键（空中可再跳一次） |
| 冲刺 | **Shift**（前移 + 无敌穿障，约 2s 冷却；画布左下有冷却条） |
| 下蹲（躲蝙蝠） | **C** / 按住鼠标右键 |
| 切换皮肤 | 开始界面 **1** 黄昏 **2** 红月 **3** 午夜，**T** 轮换 |
| 暂停 | **Esc** / **P** / 右上角暂停按钮 |
| 静音 | **M** / 右上角喇叭按钮 |
| 重开 | R / 点击画面（Game Over 后） |

未开始时按跳跃键即可出发。

## 核心玩法

### 地形与障碍

- **三种地形**：平地、高台（须跳上去）、深坑（坠落即死）
- **地面障碍**：墓碑、尖刺、栅栏 — 跳跃或冲刺穿过
- **空中障碍**：蝙蝠 — 必须下蹲钻过（跳不过去）
- 分数越高，障碍生成越密、速度越快（11 → 26）

### 收集与连击

- **金币** +15、**猫爪** +50、**魔法** +25（刷新二段跳并赋予护盾）
- **诅咒陷阱**：伪装收集物，扣分并短时加速障碍
- **连击倍率**：连续拾取提升加分倍率（最高 ×3）；踩诅咒清零
- 超越历史最高分时 HUD 显示「新纪录!」

### 操作手感

- **Coyote Time**（80ms）：刚离地瞬间仍可起跳
- **Jump Buffer**：落地前约 0.1s 按跳，落地后自动起跳
- **冲刺无敌帧**：短暂无敌穿障，带残影与光效
- 死亡时屏幕震动；碰撞径向闪光、跳跃紫色尾迹

### 视听表现

- **三层视差背景**：远景（月亮/云/星星）、中景（城堡/枯树）、近景（灌木/树桩）
- **深夜渐变**：300 分起配色从暮光过渡到深夜
- **三套皮肤**：黄昏 / 红月 / 午夜
- **像素角色**：黑猫 4 帧跑动 + 摆尾 + 眨眼；蝙蝠 4 帧扇翅
- **Web Audio**：程序化音效与 BGM，无外部音频文件
- 所有美术由 Canvas `fillRect` 绘制，**无 PNG 素材**

### 数据持久化

- **本地 Top5 排行榜**：IndexedDB 持久化，自动从旧版 localStorage 迁移
- **成就系统**：10 个成就（分数、连击、收集、冲刺、生存时间、上榜等），Game Over 高亮新解锁
- 历史最高分、主题偏好、成就进度均本地保存

### 界面

- 画布内 HUD：分数、冲刺状态、连击倍率、破纪录提示
- 画布下：开始说明面板、Game Over 面板（得分、死亡原因、本局统计、新成就）
- 页脚：历史最高分与 Top5 列表
- 移动端：窄屏 / 触屏自动显示跳、蹲、冲触控按钮

## 技术栈

- HTML5 Canvas + 原生 JavaScript（15+ 模块，无框架）
- Web Audio API（程序化音效）
- IndexedDB + localStorage（排行榜、成就、偏好）
- GitHub Pages 静态部署

## 文件结构

| 文件 | 职责 |
|------|------|
| `index.html` | 页面与脚本加载 |

| `js/main.js` | 主循环、游戏状态 |
| `js/player.js` | 玩家物理、跳跃缓冲、土狼时间 |
| `js/obstacles.js` | 障碍生成、移动、碰撞 |
| `js/platforms.js` | 高低平台生成 |
| `js/collectibles.js` | 收集物与诅咒 |
| `js/leaderboard.js` | Top5 排行榜（IndexedDB） |
| `js/achievements.js` | 成就系统 |
| `js/themes.js` | 多主题配色 |
| `js/audio.js` | Web Audio 音效与 BGM |
| `js/render.js` | 绘制与 HUD |
| `js/ui.js` | 开始/结束面板 |
| `js/touch.js` | 移动端触控 |
| `js/config.js` | 游戏参数与状态枚举 |
